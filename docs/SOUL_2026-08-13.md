### SOUL #190-#192 (8/13 上午): Bug 审计 6 修复
- **#190** `force` 参数必须显式生效 — 声明了不检查 = 等于不声明
  - 真凶: `_loadRecommendations(force: true)` 不检查 force, 守卫仍卡
- **#191** 关键词列表不能含空串 — `text.contains('')` 永远 true = 过滤失效
  - 真凶: `_sceneKeywords.relax` 含 `''` 字符串, text 永远命中
- **#192** regex 注释要跟实现一致 — "strip 思维链" 写 ``` 是骗自己
  - 真凶: `stripThinkTags` 注释说 strip MiniMax reasoning, 实际只匹配 ```

### SOUL #193-#194 (8/13 下午): 4 场景真凶链 + RSS 扩展
- **#193** 链式调用前一步可能改变长度, clamp 必须用最后一步的结果
  - 真凶: `_dedupeSimilar.normalize` `s.length.clamp(0,100)` 在 `replaceAll` 之后用
  - 中文标题缩短后 substring 越界 → RangeError → fetchByBucket 整体崩 → 24 桶全空
  - 后果: 用户看到 "今日暂无新内容", 实际是 RangeError
  - 修: `stripped.length.clamp(0,100)` — 用 replaceAll 后的长度
  - 诊断法: **flutter test 模拟 production 链路看堆栈**, 不是猜
- **#194** 多 RSS 源扩展必须同步 `ft_server.py` ALLOWED_RSS_DOMAINS 白名单
  - 真凶: 加 NPR 源但忘了白名单 → `/rss?url=npr.org/...` 返 403 `domain not allowed`
  - 修: `ALLOWED_RSS_DOMAINS = ('...', 'feeds.npr.org')` 同步

### SOUL #195-#197 (8/13 傍晚): SW 缓存 + source 错位 + 系统d env
- **#195** HTTPS 下 Flutter web 老 SW 缓存老 main.dart.js — 用户看不到新代码
  - 真凶链:
    1. `flutter-keepalive.service` 没动 → 老 SW 仍 active
    2. ft_server.py 故意返 404 阻止新 SW register → 但老 SW 仍 active 拦截 fetch
    3. 用户访问 → 返老 cached main.dart.js → 看到老版本 (4 场景内容一样)
  - 修: `web/index.html` 加 SW cleanup 脚本 — 进入页面立即 `getRegistrations() + unregister()` + `caches.delete()`
  - 验证: Puppeteer 显示 `SW controller: no SW API` ✅
- **#196** content 来源必须真实 — 跨源混杂 = 误导用户
  - 真凶: `rss_service.dart:343` source 写死 `_sourceName` → NPR item 也显示 "36氪"
  - 修: `_resolveSourceName(url)` 从 URL host 解析真实来源
  - 映射: sspai.com→少数派 / npr.org/1001→NPR / npr.org/1039→NPR Music / 36kr.com→36氪 / theverge.com→The Verge / bbci.co.uk→BBC / ximalaya.com→喜马拉雅
- **#197** systemd ExecStartPre 中 `${ENV_VAR}` 在 `/bin/bash -c '...'` 内不展开
  - 真凶链:
    1. llm-proxy systemd 启动 → EnvironmentFile 注入 env (理论上)
    2. ExecStartPre `/bin/bash -c 'printf "...%s" "${MINIMAX_CN_BASE_URL}"'` → `${VAR}` 没展开
    3. printf 拿空字符串 → `LLM_ENDPOINT=/bin/bash/chat/completions` → MiniMax 返 404
  - 修: ExecStartPre 直接 grep .env 取值, 不依赖 systemd env 注入
  - 同时补 `/chat/completions` 后缀 (server.py 默认会补, 我们覆盖 env 后要自己补)
